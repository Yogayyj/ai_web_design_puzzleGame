GitHub 工作流：上传、修改、版本管理

建立仓库、上传 index.html，并用 GitHub Pages 发布网页。

开始本课任务返回6课时总览

课堂流程

本课做什么？

  • 🚀 第一次线上发布
  • 理解 repository、commit、branch、Pages
  • 获得一个可以分享给同学访问的网址
学习重点

教师提醒

  • 文件名建议为 index.html
  • 每次修改都写清楚 commit 信息
  • 发布后检查网址是否能打开
学生产出

提交物

完成本课页面或学习单，并能用 2–3 句话说明自己修改了什么、为什么这样设计。

检查清单

下课前确认

  • 文件已保存，命名清楚。
  • 页面能在浏览器中打开。
  • 遇到问题时记录了错误现象和修改办法。

本课 AI 提示词

请用简单步骤告诉我如何把一个 index.html 上传到 GitHub，并通过 GitHub Pages 发布成网页。
