核心概念：HTML 是内容，CSS 是外观

用一个很简单的比喻：HTML 决定“页面上有什么”，CSS 决定“这些东西长什么样”。

HTML

像房子的结构：标题、段落、按钮、输入框、卡片。

CSS

像房子的装修：颜色、字体、大小、间距、圆角、阴影。

JavaScript

像房子的开关：点击按钮后判断答案、显示反馈。本节只简单看到它。

投屏讲解：从一行代码看 HTML 和 CSS 
<h1>校园密码谜题</h1>

/* CSS */
h1 {
  color: blue;
  text-align: center;
}

上面第一行是 HTML：它告诉浏览器“这里有一个大标题”。下面是 CSS：它告诉浏览器“这个大标题要变成蓝色并居中”。

实际案例：校园密码谜题网页

本节课统一使用一个简单案例练习。之后学生再把这个结构迁移到自己的 Puzzle Game 主题。

案例设定

项目内容
游戏名称校园密码谜题
游戏背景学校图书馆有一个神秘盒子，需要输入正确密码才能打开。
谜题内容密码由三个线索组成：最喜欢阅读的地点、代表智慧的动物、今天课程主题。
正确答案libraryowlai

校园密码谜题

Can you unlock the secret box?

游戏规则

根据线索猜出最终密码，并输入答案。

线索 1

密码的第一部分是：学校里最适合阅读的地方。

线索 2

密码的第二部分是：常被认为代表智慧的动物。

线索 3

密码的第三部分是：这门课的重要工具。

AI 提示词：让 AI 生成第一版网页

学生不要只输入“帮我做网页”。要告诉 AI：身份、项目、内容、功能、风格、代码难度。

我是一名初二学生，正在学习用 AI 制作 Puzzle Game 网页。
请帮我生成一个简单的 HTML、CSS、JavaScript 网页初稿。

游戏名称：校园密码谜题
游戏背景：学校图书馆有一个神秘盒子，需要输入正确密码才能打开。
游戏规则：玩家阅读 3 条线索，猜出最终密码，并点击按钮提交答案。
线索：
1. 密码的第一部分是：学校里最适合阅读的地方。
2. 密码的第二部分是：常被认为代表智慧的动物。
3. 密码的第三部分是：这门课的重要工具。
正确答案：libraryowlai

网页要求：
1. 使用一个 HTML 文件完成；
2. 代码适合初学者阅读；
3. 页面包含标题、游戏规则、三条线索、输入框、提交按钮、结果反馈；
4. CSS 风格要像一个神秘校园游戏，颜色清楚，卡片有圆角；
5. 请在代码中加入简单注释，说明 HTML、CSS、JavaScript 各自的作用。

教师提醒

AI 生成后，不要让学生直接“交作业”。本节重点是让学生修改至少 3 个地方：文字内容、页面颜色、卡片样式或按钮文字。

读代码：网页初稿由哪些部分组成？

教师可以用下面的“结构地图”带学生看 AI 代码。学生只需要先认识常见标签，不需要背全部语法。

1. 页面基本结构

<!DOCTYPE html>、<html>、<head>、<body>

2. 内容标签

<h1> 标题，<p> 段落，<div> 分区，<button> 按钮。

3. 样式选择器

body 整页，.card 卡片，button 按钮，#result 结果区。

展开：课堂讲解代码片段 
<div class="clue-card">
  <h2>线索 1</h2>
  <p>密码的第一部分是：学校里最适合阅读的地方。</p>
</div>

.clue-card {
  background-color: white;
  border-radius: 16px;
  padding: 20px;
  margin: 12px 0;
}

这里的 class="clue-card" 像给盒子贴了一个名字。CSS 通过 .clue-card 找到这个盒子，然后给它加白色背景、圆角和间距。

现场练习：修改 HTML 与 CSS

下面是一个可运行的课堂练习。左边修改代码，点击“更新预览”，右边查看效果。适合教师投屏，也适合学生自己练。

任务 A：改 HTML 内容

把标题改成自己的游戏名；把三条线索改成自己的谜题内容。

任务 B：改 CSS 外观

修改 background、color、border-radius，观察网页变化。

任务 C：改按钮与反馈

把按钮文字改成“解锁谜题”或其他符合游戏风格的文字。

学生独立迁移：把案例换成自己的游戏

学生使用自己的项目构思表，完成“替换式创作”。先不追求复杂功能，先把自己的内容放进网页。
