最小可用 JavaScript 代码 
function checkAnswer() {
  let answer = document.getElementById("answerInput").value;
  let result = document.getElementById("result");

  if (answer === "library") {
    result.textContent = "Correct! You unlocked the box.";
  } else {
    result.textContent = "Try again. Read the clue carefully.";
  }
}

JavaScript 关键概念

学生不需要一次学完 JavaScript，只要先掌握本课的 4 个关键词。

1

id

给元素取名字，方便 JavaScript 找到它。比如 id="answerInput"。

2

value

读取输入框里的内容。比如 input.value。

3

if / else

如果答案正确，就做一件事；否则做另一件事。

4

textContent

修改页面上的文字，用来显示反馈。

注意：大小写和空格会影响判断

如果玩家输入 Library 或 library ，可能和 library 不完全相同。后面可以用 toLowerCase() 和 trim() 解决。

AI 协作：让 AI 帮你生成交互代码

本节课的提示词要比第2课更具体：不是“做一个网页”，而是“加输入框、按钮和判断反馈”。

我正在制作一个 Puzzle Game 网页。请帮我在现有 HTML 中加入简单的 JavaScript 交互。
要求：
1. 页面中有一个输入框，让玩家输入答案；
2. 有一个按钮，点击后检查答案；
3. 如果答案正确，显示“Correct! You solved the puzzle!”；
4. 如果答案错误，显示“Try again. Look at the clue carefully.”；
5. 请使用初学者能看懂的代码，并用注释解释每一步；
6. 正确答案是：library。
教师提醒：不要让 AI 一次生成太复杂

本节课不要要求 AI 加计分、关卡、动画、排行榜。先让学生完成一个可以运行的判断功能。

挑战任务：增加一个按钮，点击后显示额外提示。

Debug：为什么按钮点了没反应？

交互代码最常见的问题不是“完全不会”，而是名字对不上、符号漏掉。

1. id 名字是否一致？

id="answerInput" 和 getElementById("answerInput") 必须一模一样。

2. 函数名是否一致？

按钮里的 onclick="checkAnswer()" 必须和函数名一样。

3. 引号和括号是否完整？

少一个 "、) 或 }，代码都可能停止运行。

给 AI 的 Debug 提示词 
我的 HTML/JavaScript 代码中，点击按钮后没有反馈。请帮我检查：
1. input 的 id 和 getElementById 是否一致；
2. button 的 onclick 和 function 名字是否一致；
3. if/else 的括号是否完整；
4. 是否有拼写错误。
请用初学者能理解的方式指出问题，不要重写整个项目。
